# NOIR — Burger & More

**BOLD FLAVORS. UNFORGETTABLE BITES.**

A modern, responsive restaurant ordering website built with React.js and Vite as part of the CSCI426 – Advanced Web Programming course.

## About the Project

NOIR is a premium burger and fast-food restaurant website designed to provide customers with a smooth and attractive online ordering experience.

The website combines a cinematic dark design with an orange and cream color palette to create a modern restaurant brand identity.

Customers can explore the menu, view product details, add products to their shopping cart, and submit their orders through WhatsApp.

## Main Features

- Responsive homepage with a cinematic hero section.
- About page introducing the restaurant.
- Interactive food menu.
- Product details pages.
- Shopping cart with quantity management.
- Checkout form.
- WhatsApp order submission.
- Contact page.
- Responsive layout for desktop and mobile devices.

## Technologies Used

## Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd noir-restaurant
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```

## Ordering Process

1. Browse the restaurant menu.
2. Select a food item.
3. View its details.
4. Add it to the shopping cart.
5. Review the order.
6. Complete the checkout form.
7. Send the order through WhatsApp.

**Note:** This project implements a frontend ordering experience. It does not process online payments or use a backend database.
